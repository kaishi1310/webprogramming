# Website Repair Page

Website ini merupakan project perbaikan halaman (repair page) yang bertujuan untuk meningkatkan kualitas tampilan dan performa website agar lebih modern dan user-friendly.

## 🚀 Fitur Utama
- Desain modern dan menarik
- Responsive (mobile & desktop)
- Perbaikan bug tampilan
- Struktur kode lebih rapi

## 🛠️ Teknologi yang Digunakan
- HTML
- CSS3

## 📂 Struktur Project
/assets → berisi gambar & file pendukung  
/index.html → halaman utama  
/style.css → styling website  

## ▶️ Cara Menjalankan
Cukup buka file `index.html` menggunakan browser favorit kamu.

## 📌 Tujuan Project
Project ini dibuat untuk latihan dan meningkatkan skill dalam pengembangan website.
